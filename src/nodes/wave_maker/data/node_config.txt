# ============================================================================
# WAVE MAKER HARDWARE NOTES
# ============================================================================
# Platform: ESP8266 WEMOS D1 Mini
# PWM Pin: D1 (GPIO5)
# Output: MOSFET gate driving 12V DC pump
#
# PWM Configuration:
#   - Frequency: 200Hz (set via analogWriteFreq)
#   - Resolution: 10-bit (0-1023, set via analogWriteRange)
#   - Max Duty Cycle: 95%
#   - Min Duty Cycle: 30% (below this pump stalls)
#
# Soft Start:
#   - Sinusoidal ramp from 0% to target over 3 seconds
#   - Uses sin(0..π/2) curve for smooth acceleration
#
# Command Format from Hub:
#   Command Type 0: STOP (D1 LOW, pump off)
#   Command Type 1: PWM
#     - data[1-4] = duty cycle % (float, little-endian)
#   Command Type 40: Status request
#
# Fail-Safe: STOP pump (D1 LOW) - safer to stop flow than risk uncontrolled pump
