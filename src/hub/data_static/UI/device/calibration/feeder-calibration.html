How to Calibrate

  1. If the disk is not dispensing a complete portion of food, press the < button to decrease the duty cycle.
  2. If too much food is dispensed, press the > button to increase the duty cycle.
  3. Use << and >> for larger adjustments.
  4. Press Test a few times to verify the calibration.
  5. Once satisfied, press Save to persist the settings.
